# VOIS_AICTE_Oct2025_Navinkumar_Airbnb_Hotel_Booking_Analysis

## 📌 Overview
This repository contains my **Major Internship Project** completed during the **VOIS AICTE Virtual Internship Program (October 2025)**.  
The project focuses on analyzing Airbnb hotel booking data to uncover valuable insights related to customer behavior, pricing trends, booking patterns, and business opportunities using data analytics techniques.

The objective was to work on real-world hospitality data, perform detailed analysis, and gain practical experience in solving business problems through analytics.

## 🎯 Project Objective
To perform detailed analysis on Airbnb hotel booking dataset and answer key business questions such as:

- Which locations have the highest bookings?
- What pricing patterns exist across listings?
- Which room types are most preferred?
- How do reviews impact bookings?
- What factors affect customer choices?
- Seasonal booking trend analysis

---

## 📂 Dataset Information
The dataset contains booking and listing related attributes such as:

- Listing ID  
- Host Name  
- Location  
- Room Type  
- Price  
- Availability  
- Number of Reviews  
- Ratings  
- Booking Frequency  
- Minimum Nights  
- Last Review Date

---

## 📊 Key Insights

- Private rooms and entire homes were highly demanded.
- Popular locations generated higher booking frequency.
- Listings with strong reviews performed better.
- Pricing varied significantly by area and room type.
- Seasonal demand impacted availability and prices.
- Customer ratings strongly influenced booking behavior.
